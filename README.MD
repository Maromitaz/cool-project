# Cool project

The whole point of this project is to learn how to combine multiple languages in different ways and work with them.

Is it going to be something revolutionary?

No.

It's just an oportunity to learn how to bind C++ with python and JavaScript in a way that it doesn't need to use python's complicated (in my opinion) wheels and/or cython and whatever do I need to make python work with any language.

The same applies with JavaScript. All I want is to make a minimalist app that can run natively using these two languages.

Is it "production ready"?

No, never will be. As I've said. This is only an oportunity to learn. Nothing more.
